# Data Science Foundations

Notebooks covering the core Python libraries used in data science — NumPy and Pandas. This repo serves as a practical reference for data manipulation, array operations, and analysis workflows.

## Contents

### 📐 NumPy
Covers array creation, indexing, slicing, broadcasting, mathematical operations, and reshaping. NumPy is the backbone of numerical computing in Python and a prerequisite for libraries like Pandas and Scikit-learn.

### 🐼 Pandas
Covers DataFrames and Series, reading and writing data, filtering and grouping, handling missing values, merging datasets, and basic statistical summaries. Pandas is the go-to tool for structured data analysis.

## Tech Stack

- **Language:** Python 3
- **Libraries:** NumPy, Pandas
- **Environment:** Jupyter Notebook

## How to Run

```bash
git clone https://github.com/Adithyan-7/data-science-portfolio.git
cd data-science-portfolio
pip install numpy pandas jupyter
jupyter notebook
```

Open the `Numpy/` or `Pandas/` folder and run the notebooks inside.

## Why This Repo

These two libraries form the foundation of almost every data science workflow. Mastering them is the first step before moving into visualisation, machine learning, or deep learning.
